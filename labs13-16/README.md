# Материалы практических работ 13–16

Терешин Артем Дмитриевич, ЭФБО-14-24.

- `gitops/`: Application Argo CD. Манифесты приложения и PR1/PR2 находятся в отдельном репозитории https://github.com/teret457/devops-gitops.
- `istio/`: сценарий воспроизведения Bookinfo, правила распределения, политика mTLS и клиент подсчёта версий.
- `patterns/`: локальные модели Retry, Circuit Breaker, Cache Aside и шесть тестов unittest.
- `artifactory/`: настройки реестра, собственный Docker-артефакт и проверка push/pull.

Версии закреплены в versions.json. Секреты, kubeconfig, приватные ключи и файлы Docker login в Git не публикуются. Установка локальная, без платного облака. Образцы Bookinfo принадлежат проекту Istio.

Отчёты содержат настоящие скриншоты выполненных команд; ошибки и исправления описаны отдельно. Скриншоты не заменяют исходные файлы: перед защитой повторите команды из README соответствующей работы.
